# Manual end-to-end test

This is the live household visual check. Use the installed `SecureBudgetManager.exe`. There is no master password.

1. Launch installed Secure Budget Manager.
2. Confirm it opens directly to the populated Dashboard.
3. Confirm there is no unlock, vault-creation or pending-import screen.
4. Close and reopen.
5. Confirm records remain.
6. Compare Payroll and Dashboard.
7. Inspect This Week.
8. Inspect grocery current and fallback plans.
9. Confirm adult earners have separate discretionary balances.
10. Confirm dependants have no personal allowance unless one was recorded.
11. Create and restore a local database backup after you are satisfied. Confirm the warning that the file contains household information.
12. Capture full-page screenshots of the major pages. Confirm the PNG warning.
13. Confirm the window remains readable on both 1366×768 monitors.
14. Use Privacy once, then restart and confirm the Dashboard opens normally.

Do not copy household names or figures into source, tests, chat tickets or installer assets.
