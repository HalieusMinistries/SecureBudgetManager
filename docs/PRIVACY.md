# Privacy

Secure Budget Manager is local-only.

- Household data stays on this computer in an ordinary SQLite file.
- There is no cloud account, no analytics and no bank login.
- Screenshots (PNG), CSV exports and local database backups all contain household financial information. Anyone with those files may read them.
- The Privacy screen hides figures while the programme is running. It is not database encryption. Restarting opens the Dashboard normally.
- Uninstall keeps the local database and backups unless the user explicitly removes them.

Store backups, CSV files and screenshots only in a trusted location.
